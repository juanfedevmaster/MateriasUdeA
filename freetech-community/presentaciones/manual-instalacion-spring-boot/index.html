1. Instalar Java 21 (JDK)

Usaremos Eclipse Temurin 21 LTS, una distribución gratuita de OpenJDK. Temurin 25 LTS también sirve: Spring Boot 4 funciona con Java 17 a 26. Descarga siempre desde adoptium.net e instala el JDK, no el JRE.

Windows

  1. En adoptium.net elige Windows, x64, JDK, versión 21, y descarga el instalador .msi.
  2. En la pantalla de funciones activa Add to PATH y Set JAVA_HOME variable (esta última viene desactivada por defecto).
  3. Termina la instalación y abre una terminal nueva (PowerShell).

Alternativa por consola:

winget install EclipseAdoptium.Temurin.21.JDK

macOS

  1. Descarga el .pkg de Temurin 21: aarch64 si tu Mac tiene chip Apple (M1 en adelante), x64 si es Intel.
  2. Ejecuta el instalador.
  3. Configura JAVA_HOME agregando esta línea al archivo ~/.zshrc:
export JAVA_HOME=$(/usr/libexec/java_home -v 21)

Alternativa con Homebrew:

brew install --cask temurin@21

Linux (Ubuntu o Debian)

sudo apt install -y wget apt-transport-https gpg
wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/adoptium.gpg > /dev/null
echo "deb https://packages.adoptium.net/artifactory/deb $(awk -F= '/^VERSION_CODENAME/{print$2}' /etc/os-release) main" | sudo tee /etc/apt/sources.list.d/adoptium.list
sudo apt update
sudo apt install -y temurin-21-jdk

Luego agrega JAVA_HOME al archivo ~/.bashrc:

export JAVA_HOME=/usr/lib/jvm/temurin-21-jdk-amd64

Verificar

En una terminal nueva ejecuta:

java -version
javac -version

Ambos deben mostrar la versión 21 (o la que instalaste). Si javac no se reconoce, instalaste el JRE en lugar del JDK.

2. Instalar Visual Studio Code

Descarga VS Code desde code.visualstudio.com y luego instala dos paquetes de extensiones: uno para Java y otro para Spring Boot.

Windows

  1. Descarga el User Installer para x64.
  2. En el instalador marca Agregar a PATH y Agregar la acción "Abrir con Code" al menú contextual.

macOS

  1. Descarga el .zip (Universal), descomprímelo y arrastra Visual Studio Code a la carpeta Aplicaciones.
  2. Abre VS Code, presiona Cmd+Shift+P y ejecuta Shell Command: Install 'code' command in PATH.

Linux (Ubuntu o Debian)

  1. Descarga el paquete .deb.
  2. Instálalo desde la carpeta de descargas:
sudo apt install ./code_*.deb

Extensiones necesarias

Abre la vista de extensiones (Ctrl+Shift+X, o Cmd+Shift+X en macOS) e instala:

ExtensiónQué incluye
Extension Pack for Java (Microsoft)Soporte del lenguaje, depurador, pruebas, Maven y gestor de proyectos
Spring Boot Extension PackSpring Initializr, Spring Boot Dashboard y ayuda en application.properties

También puedes instalarlas desde la terminal:

code --install-extension vscjava.vscode-java-pack
code --install-extension vmware.vscode-boot-dev-pack

Verificar

  1. Presiona Ctrl+Shift+P (Cmd+Shift+P en macOS) y ejecuta Java: Configure Java Runtime.
  2. Debe aparecer el JDK 21 que instalaste. Si no aparece, revisa JAVA_HOME y reinicia VS Code.

3. Instalar PostgreSQL

Instala PostgreSQL 18. La versión 19 salió el 19 de noviembre de 2026 y también funciona. Tienes dos caminos: instalarlo directo en tu sistema (opción A) o correrlo con Docker (opción B), que es el que usaremos en clase desde la semana 2.

Opción A: instalación directa

  1. Descarga el instalador de EDB desde postgresql.org/download/windows.
  2. Deja marcados PostgreSQL Server, pgAdmin 4 y Command Line Tools. Stack Builder no es necesario.
  3. Define una contraseña para el usuario postgres y anótala. Deja el puerto 5432.
  4. Agrega C:\Program Files\PostgreSQL\18\bin a la variable PATH para usar psql en la terminal.
brew install postgresql@18
brew services start postgresql@18

Con Homebrew el superusuario es tu usuario de macOS, no postgres. Otra opción sencilla es Postgres.app.

sudo apt install -y postgresql-common
sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh
sudo apt install -y postgresql-18

Crear la base de datos y el usuario del curso. Conéctate como superusuario:

psql -U postgres -h localhost
sudo -u postgres psql

Luego ejecuta:

CREATE USER freetech WITH PASSWORD 'freetech123';
CREATE DATABASE cursospring OWNER freetech;

Sal con \q. Estas credenciales son solo para tu equipo local; nunca las uses en un servidor real.

Opción B: con Docker

Requiere Docker Desktop instalado. Crea un archivo docker-compose.yml:

services:
  postgres:
    image: postgres:18
    container_name: freetech-postgres
    environment:
      POSTGRES_USER: freetech
      POSTGRES_PASSWORD: freetech123
      POSTGRES_DB: cursospring
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql
volumes:
  pgdata:

Levántalo con:

docker compose up -d

Con esta opción la base de datos y el usuario del curso ya quedan creados.

Verificar

psql -h localhost -U freetech -d cursospring -c "SELECT version();"

Debe mostrar la versión de PostgreSQL. Con Docker, si no tienes psql instalado, usa:

docker exec -it freetech-postgres psql -U freetech -d cursospring

4. Prueba final: tu primer proyecto

Si este proyecto arranca sin errores, tu entorno está listo para el curso.

  1. En VS Code presiona Ctrl+Shift+P (Cmd+Shift+P en macOS) y ejecuta Spring Initializr: Create a Maven Project.
  2. Responde así:
    • Versión de Spring Boot: la estable más reciente (sin SNAPSHOT ni M)
    • Lenguaje: Java
    • Group Id: com.freetech · Artifact Id: demo
    • Packaging: Jar · Versión de Java: 21
    • Dependencias: Spring Web, Spring Data JPA y PostgreSQL Driver
  3. Elige una carpeta y abre el proyecto cuando VS Code lo ofrezca.
  4. Abre src/main/resources/application.properties y agrega:
spring.datasource.url=jdbc:postgresql://localhost:5432/cursospring
spring.datasource.username=freetech
spring.datasource.password=freetech123
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
  1. Ejecuta la aplicación desde el Spring Boot Dashboard (botón de play) o desde la terminal del proyecto:
./mvnw spring-boot:run
mvnw.cmd spring-boot:run
Resultado esperado: en la consola aparecen HikariPool-1 - Start completed (conectó a PostgreSQL) y Tomcat started on port 8080. Si abres http://localhost:8080 verás una página de error 404 (Whitelabel Error Page): es normal, porque aún no hay controladores.
