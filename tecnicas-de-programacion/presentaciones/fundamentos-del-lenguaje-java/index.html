    Concepto

    Java y la máquina virtual

    Java es un lenguaje de programación de propósito general, orientado a objetos, que compila el código fuente (.java) a bytecode (.class) en lugar de código máquina nativo.

    Ese bytecode lo ejecuta la Máquina Virtual de Java (JVM) — es la capa que permite que el mismo programa corra en Windows, Linux o macOS sin recompilar.

    Concepto

    JDK, JRE y JVM: quién hace qué

    ComponenteQué incluyePara qué sirve
    JVMEl motor que ejecuta bytecodeCorrer programas Java ya compilados
    JREJVM + librerías estándarEjecutar programas Java (sin poder compilarlos)
    JDKJRE + compilador (javac) + herramientasEscribir y compilar código — lo que usaremos en el curso

    En este curso usaremos JDK 21, sujeto a la disponibilidad de las salas de cómputo.

    Concepto

    El IDE del curso

    Un IDE (Entorno de Desarrollo Integrado) agrupa editor de código, compilador, depurador y gestor de proyectos en un solo programa.

    • Apache NetBeans — el IDE de referencia del curso, disponible en las salas de cómputo.
    • Alternativas válidas para trabajar desde casa: IntelliJ IDEA (edición Community) o Visual Studio Code con el paquete de extensiones para Java.

    Lo importante no es el IDE — es que el proyecto compile y corra igual en cualquiera de ellos.

    Concepto

    La estructura mínima de un programa

    Todo programa Java ejecutable necesita, como mínimo, una clase pública y un método main — el punto de entrada que la JVM busca primero.

    public class Main {
    public static void main(String[] args) {

    }
}

    El nombre del archivo (Main.java) debe coincidir exactamente con el nombre de la clase pública que contiene.

    Concepto · Ejemplo

    Hola Mundo

    public class Main {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}

    System.out.println(...) imprime el texto en la consola y agrega un salto de línea al final. Es la forma más simple de ver qué está haciendo un programa mientras se aprende.

    Concepto

    Tipos de datos primitivos

    TipoQué guardaEjemplo
    intNúmeros enterosint edad = 25;
    doubleNúmeros decimalesdouble precio = 19.99;
    charUn solo carácterchar inicial = 'J';

    Java es un lenguaje de tipado estático: cada variable declara su tipo, y ese tipo no cambia durante la ejecución.

    Contraejemplo

    No todo son primitivos

    String, los arreglos y cualquier clase (incluidas las que ustedes definan) son tipos de referencia: la variable no guarda el valor directamente, guarda una dirección hacia donde está el objeto en memoria.

    Esa diferencia explica por qué comparar dos String con == no siempre funciona como se espera — se profundizará en esto más adelante en el curso, al trabajar con objetos.

    Síntesis

    Lo que hay que llevarse de hoy

    1. El código Java se compila a bytecode y lo ejecuta la JVM — por eso corre igual en cualquier sistema operativo.
    2. El JDK es lo que instalamos para escribir y compilar; el JRE (incluido en el JDK) es lo que ejecuta.
    3. Todo programa ejecutable necesita una clase pública con un método main.
    4. Java distingue tipos primitivos (guardan el valor) de tipos de referencia (guardan una dirección).
    5. Las convenciones de nombres (camelCase, PascalCase, MAYÚSCULAS) no son opcionales en este curso.
