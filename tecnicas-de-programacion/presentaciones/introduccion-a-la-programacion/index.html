Convenciones de nombres · 1/4

Notación Camel en Java

La notación camel en Java es una práctica para escribir nombres de métodos, funciones, variables, clases, paquetes y constantes.

La razón es simple: tener un formato único y legible al escribir código en Java.

Convenciones de nombres · 2/4

Clases, métodos y funciones

Clase: el nombre debe ser un sustantivo, acorde al objetivo que cumple en el programa, como Lease o Logger. Si el nombre es compuesto, cada palabra inicia con mayúscula, por ejemplo LeasesRenters.

Método o función: se supone que hace algo, por lo tanto debe ser un verbo. La primera letra va en minúscula y, si hay una segunda palabra, esta inicia en mayúscula. Por ejemplo:

  • getLeases()
  • getRenters()

Convenciones de nombres · 3/4

Interfaces y variables

Interfaces: son adjetivos y comienzan con mayúscula. En general se puede agregar la palabra "able" si es necesario, por ejemplo:

  • Runnable
  • Remote
  • Serializable

Variables: el nombre debe ser corto y significativo. Si tiene más de una palabra, la segunda inicia en mayúscula:

  • flag
  • name
  • lastName
  • cellphone

Convenciones de nombres · 4/4

Constantes y paquetes

Constantes: al igual que las variables, deben ser cortas y significativas, pero completamente en mayúsculas con palabras separadas por guion bajo ("_"):

COMPANY_NAME = "UdeA"

Paquetes: el prefijo de un nombre de paquete se escribe siempre en minúsculas ASCII y debe ser uno de los dominios de nivel superior, como com, edu, gov, mil, net, org.

java.util.Scanner;
java.io.*;

Introducción al lenguaje Java

JDK vs. JRE

JDK (Java Development Kit): usaremos Java 21 en la medida de lo posible, condicionado a la disponibilidad en las salas de cómputo.

JRE (Java Runtime): la última versión es la 8. La diferencia con el JDK es que el JRE solo instala lo necesario para ejecutar programas ya compilados en Java.

Descarga del JDK: adoptium.net/temurin/releases

Condicionales

Operadores relacionales:

  • Menor que: a < b
  • Menor o igual que: a <= b
  • Mayor que: a > b
  • Mayor o igual que: a >= b
  • Igual a: a == b
  • Distinto de: a != b

Sentencias condicionales: if(condición), else, else if(condición), switch
