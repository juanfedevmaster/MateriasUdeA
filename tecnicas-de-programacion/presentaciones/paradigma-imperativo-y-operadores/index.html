    Concepto

    El paradigma imperativo

    Un paradigma de programación es una forma de pensar y organizar la solución a un problema en código — no es un lenguaje, es un enfoque que varios lenguajes pueden compartir.

    El paradigma imperativo describe un programa como una secuencia de instrucciones que modifican el estado del programa paso a paso: se asigna, se compara, se repite, se decide.

    Java, C, C# y Python (en su uso más común) siguen este paradigma — es el que usaremos como base durante todo este curso.

    Concepto

    Sintaxis, semántica y pragmática

    PerspectivaQué estudiaEjemplo
    SintaxisLas reglas para escribir una instrucción válidaint x = 5; es válido; int 5 = x; no lo es
    SemánticaEl significado de esa instrucciónint x = 5; significa "reservar memoria para un entero y guardar 5"
    PragmáticaCómo el contexto cambia la interpretación del problemaEl mismo problema se resuelve distinto según el lenguaje y las herramientas disponibles

    Como en cualquier idioma: las letras forman palabras, las palabras forman oraciones. En un lenguaje de programación, los caracteres forman sentencias, y un conjunto de sentencias forma las instrucciones del programa.

    Contraejemplo

    Un mismo significado, dos sintaxis

    // Java
System.out.println("Hola Mundo");

# Python
print("Hola Mundo")

    Ambas instrucciones tienen la misma semántica — imprimir un texto en consola — pero una sintaxis completamente distinta. Confundir "cómo se escribe" con "qué significa" es un error común al empezar.

    Concepto · Repaso

    Variables y literales

    Una variable es un espacio de memoria cuyo valor puede cambiar durante la ejecución del programa; un literal es la representación directa de un valor en el código fuente (5, "Hola", true).

    int edad = 20;     // edad es variable, 20 es literal
edad = 21;         // el valor cambia, la variable sigue siendo la misma

    Los operadores que siguen trabajan sobre estos dos elementos: variables y literales.

    Ojo con la división entera: 7 / 2 en Java da 3, no 3.5, porque ambos operandos son int. Para obtener el decimal, al menos uno debe ser double.

    Concepto

    Jerarquía y precedencia

    Igual que en álgebra, Java evalúa una expresión aritmética siguiendo un orden de precedencia: primero paréntesis, luego multiplicación/división/módulo, y por último suma/resta.

    int resultado = 2 + 3 * 4;     // 14, no 20
int resultado2 = (2 + 3) * 4;  // 20

    Cuando la precedencia no es obvia para quien lee el código, usar paréntesis explícitos es más claro que confiar en que todos recuerden el orden.

    Síntesis

    Lo que hay que llevarse de hoy

    1. El paradigma imperativo describe un programa como una secuencia de instrucciones que modifican el estado.
    2. Sintaxis es la forma; semántica es el significado; pragmática es el contexto de uso.
    3. Los operadores aritméticos siguen una jerarquía de precedencia — los paréntesis nunca sobran cuando hay duda.
    4. Los operadores relacionales siempre devuelven boolean; los operadores lógicos (&&, ||, !) combinan esos booleanos.
